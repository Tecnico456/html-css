Exercício 27 - Flexbox

O Flexbox é um modelo de layout do CSS que permite organizar elementos em uma página de forma flexível e responsiva. Ele facilita a criação de layouts complexos, alinhando e distribuindo espaço entre os itens dentro de um contêiner, mesmo quando seu tamanho é desconhecido ou dinâmico. Com o Flexbox, é possível controlar a direção, o alinhamento e a ordem dos elementos, tornando o design mais adaptável a diferentes tamanhos de tela e dispositivos.

O flex-basis define a largura base de cada item no contêiner flexível. Ele especifica o tamanho inicial do item antes de qualquer espaço adicional ser distribuído. Por exemplo, se você definir flex-basis: 250px, cada item terá uma largura inicial de 250 pixels. Se houver espaço extra no contêiner, os itens podem crescer ou encolher dependendo das propriedades flex-grow e flex-shrink.

O flex-grow determina a capacidade de um item crescer em relação aos outros itens no contêiner. Se você definir flex-grow: 1, o item poderá ocupar espaço adicional disponível no contêiner, aumentando sua largura proporcionalmente. Se todos os itens tiverem flex-grow: 1, eles crescerão igualmente para preencher o espaço extra; se um item tiver flex-grow: 0, ele não crescerá, mesmo que haja espaço disponível.

O flex-shrink define a capacidade de um item encolher em relação aos outros itens no contêiner. Se você definir flex-shrink: 1, o item poderá reduzir sua largura quando não houver espaço suficiente no contêiner. Se todos os itens tiverem flex-shrink: 1, eles encolherão igualmente para se ajustarem ao espaço disponível; se um item tiver flex-shrink: 0, ele não encolherá, mesmo que o espaço seja limitado.
